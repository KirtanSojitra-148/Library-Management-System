# Library-Management-System

Overview

The Library Management System is a Python-based application designed to simplify library operations. It allows users to register, log in, and manage book records efficiently. The project is easy to use and is suitable for learning Python programming concepts.

Features

- User Registration
- User Login
- Add Book Details
- View Book Details
- Search Books
- Delete Books
- Store Multiple Book Records
- Simple and User-Friendly Interface

Technologies Used

- Python 3
- VS Code / PyCharm

Modules

1. Registration Module
2. Login Module
3. Book Module

How to Run

1. Install Python 3 on your computer.
2. Open the project in VS Code or PyCharm.
3. Run the main Python file.
4. Register a new user.
5. Log in using your username and password.
6. Manage book records using the available options.

Project Structure

Library_Management_System/
│── registration.py
│── login.py
│── book.py

Future Enhancements

- Book Issue and Return
- Student Management
- Fine Calculation
- Database Integration (MySQL/SQLite)
- GUI using Tkinter

Conclusion

This project demonstrates the basics of Python programming, including user registration, login authentication, and book management. It provides a simple and effective way to organize library records and can be enhanced with additional features in the future.
